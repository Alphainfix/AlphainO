# Delta budget class exercise

Turn [[Orvine delta sediment budget]] into a two-hour exercise for the second-year course.

- Give students the before and after loads and the reservoir numbers, and let them build the budget in a spreadsheet.
- Then ask: which would help more, a bypass tunnel at Kessel or reopening the sill?
- Groups of three; each group presents one option in five minutes.
- Mark on the reasoning, not the final number.
